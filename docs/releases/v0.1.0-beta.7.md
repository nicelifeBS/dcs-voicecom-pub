Seventh beta of DCS VoiceCom: offline voice control for DCS World. This release adds **server profiles**: commands that turn on by themselves when you join a matching multiplayer server.

> **Beta.** Server profiles were tested with automated tests, not yet on a live multiplayer server. Please report what you find in Issues.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-0.1.0-beta.7.exe` below and run it. It installs over earlier betas; your settings and profiles are kept.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save.
4. To use server profiles: **Settings → DCS hook → Install**, then restart DCS.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

No breaking changes: profiles from beta 6 work as they are.

## What's new

### Server profiles

- Some commands only make sense on one server, like its own F10 comms menu items. Put them in a **server profile**. It turns on when you join a matching server and off when you leave.
- New **DCS hook** (Settings → DCS hook → Install). It tells the app the server name, address, mission and map. It only uses DCS calls that are safe on a multiplayer client.
- **+ Server profile** starts with the name of the server you are on.
- The **Servers** box lists the servers a profile is for, one per line. `*` matches any text, anywhere: `ShadowReapers*`, `*Reapers*`, `*PvE`. A server address works too.
- Commands merge in this order: aircraft, server profile, *common*. If names clash, the first wins.
- No DCS at hand? Pin a server profile in the drop-down below the profile list. Pick *Auto* to follow the server again.
- Help has a new page: **Server profiles**.

### Main window

- The command list is sorted A-Z.
- The top bar fits narrow windows and shows only the aircraft profile.
- Common and server profiles have their own color in the profile list and stay below the aircraft profiles.

## Known limits

- **Server profiles need the DCS hook installed** and DCS restarted once.
- Learn from display needs DCS running and the right display picked. Check the fields and ranges before saving.
- A dial that pushes the rest of the display to the right when it passes 9 (A-10C II FM radio `0-15`, issue 5) can't be learned or used yet. The app tells you why.
- The F-14 UHF preset command is still in the old format.
- A `{text}` slot takes any word, so a misheard word is typed as well. The display check catches it.
- Windows 10/11 x64 only.
- Installer is not code-signed.
