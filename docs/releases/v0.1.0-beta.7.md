Seventh beta of DCS VoiceCom: offline voice control for DCS World. This release adds **server profiles**, commands that turn on by themselves on a multiplayer server, and **shared aircraft profiles**: one profile now covers all variants of a jet.

> **Beta.** Server profiles and the DCS hook were tested with automated tests and a probe hook, not yet in a long live session. Please report what you find in Issues.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-0.1.0-beta.7.exe` below and run it. It installs over earlier betas; your settings and profiles are kept.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save.
4. For server profiles: **Settings → DCS hook → Install**, then restart DCS.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

No breaking changes: profiles from beta 6 work as they are.

## What's new

### Server profiles

- Put commands for one multiplayer server, like its own F10 comms menu items, in a **server profile**.
- It turns on when you join a matching server and off when you leave.
- **+ Server profile** starts one with the name of the server you're on.
- **Servers** lists the servers it is for. `*` stands for any text: `ShadowReapers*`, `*Reapers*`, `*PvE`. A server address works too.
- Commands are merged in this order: aircraft, then server profile, then *common*. The first one with a name wins.
- Below the profile list: the server you're on, and a drop-down to pin a server profile for testing without DCS.
- A small **DCS hook** (Settings → DCS hook → Install) tells the app which server you're on. It goes into `Saved Games\DCS\Scripts\Hooks`.

### One profile per jet

- The **New profile** list shows one entry per jet, not every name DCS-BIOS knows. It went from 181 names to about 100.
- Variants share a profile: every F-16D and the F-16I use **F-16C_50**, every Tomcat uses **F-14**, every Mirage F1 uses **MirageF1**.
- A profile named after the variant comes first. Make an **F-14BU** profile, and only the F-14B(U) uses it; the other Tomcats still use **F-14**.
- The log says when a shared profile is used, and the profile list marks it active.
- Jets that only share the generic Flaming Cliffs controls (F-15C, Su-27, …) keep their own profiles.
- `VSN_` mods are left out of the list. You can still type the name.
- The sample F-14 profile is now called **F-14** and covers every Tomcat. An existing `F-14BU` profile stays and still works for the F-14B(U).

### Main window

- The command list is sorted A–Z by voice line.
- The top bar fits narrow windows: the status text gets shorter, the buttons stay.
- *Common* and server profiles have their own color and are listed below the aircraft.

## Known limits

- **Server profiles need the DCS hook** and a DCS restart after installing it. Without it, pin the server profile by hand.
- A dial that pushes the rest of the display to the right when it passes 9 (A-10C II FM radio `0-15`, issue 5) can't be learned or used yet.
- The F-14 UHF preset command is still in the old format.
- A `{text}` slot takes any word, so a misheard word is typed as well. The display check catches it.
- Windows 10/11 x64 only.
- Installer is not code-signed.
