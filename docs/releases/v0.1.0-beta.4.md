Fourth beta of DCS VoiceCom: offline voice control for DCS World. This release adds **button presses**, so one action can click a push button such as an MFD key: push it in, hold it, let it out.

> **Beta.** Button presses were tested in DCS with the JF-17. Other parts still have little testing against a live DCS session. Please report what you find in Issues.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-0.1.0.exe` below and run it. It installs over earlier betas; your settings and profiles are kept.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

## What's new

- **Button press:** a DCS-BIOS action can now be a click instead of leaving the button in one state. It sends the *in* value, waits, then sends the *out* value.
  - Defaults: in `1`, out `0`, held for 50 ms. All three can be changed right in the action row.
  - Tick **button press** on any DCS-BIOS action to turn it into a click.
  - The button is always released, even if you cancel the command mid-press.
  - In profile files this is two new fields on a `bios` step: `press_ms` and `release`.
- **BUTTON chip:** in the control browser, controls with two states (like the JF-17 MFCD keys) get a **BUTTON** chip next to TOGGLE. It adds one press action, or a new "Press …" command when none is selected.
- **Seeded push buttons:** **Seed…** now makes one press action per push button instead of three (1, wait, 0).
- **Wait step:** **+ Wait** now offers 100 ms instead of 500 ms, then the last wait time you entered until the app closes.

Existing profiles load unchanged.

## Known limits

- DCS-BIOS can't tell a switch from a button, so the BUTTON chip also shows on two-position switches.
- Windows 10/11 x64 only.
- Installer is not code-signed.
