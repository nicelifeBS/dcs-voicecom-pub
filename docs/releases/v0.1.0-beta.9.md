Ninth beta of DCS VoiceCom: offline voice control for DCS World. This is a **bug-fix release**: saving a profile works again.

> **Beta.** Tested in a live DCS session: saving profiles and seeding. Please report what you find in Issues.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-0.1.0-beta.9.exe` below and run it. It installs over earlier betas; your settings and profiles are kept.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save.
4. To use server profiles: **Settings → DCS hook → Install**, then restart DCS.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

No breaking changes: profiles from beta 8 work as they are.

## Fixed

- **Save writes to the profile you opened.** A profile file that was copied or renamed (for example `F-14.json` made from an older Tomcat profile) still had the old aircraft name inside. Save used that name, so the edits went to another file (`F-14A-95-GR.json`) and looked lost. Seeded commands went missing the same way.
- The file name is now always the profile's name.

### If you lost edits in beta 8

Look in your profiles folder (`%LOCALAPPDATA%\DcsVoiceCom\profiles`) for an extra file named after a variant, like `F-14A-95-GR.json`. It has the edits you saved. Copy its commands into the right profile, or delete it.

## Known limits

- **Server profiles need the DCS hook installed** and DCS restarted once.
- Learn from display needs DCS running and the right display picked. Check the fields and ranges before saving.
- A dial that pushes the rest of the display to the right when it passes 9 (A-10C II FM radio `0-15`, issue 5) can't be learned or used yet. The app tells you why.
- The F-14 UHF preset command is still in the old format.
- A `{text}` slot takes any word, so a misheard word is typed as well. The display check catches it.
- Windows 10/11 x64 only.
- Installer is not code-signed.
