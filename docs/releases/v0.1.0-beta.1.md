First public beta of DCS VoiceCom: offline voice control for DCS World, built as a DCS-only replacement for VoiceAttack.

Push a HOTAS button, speak, and the command acts on the cockpit through DCS-BIOS, with keyboard shortcuts as a fallback. Speech runs on your CPU with Cactus Whistle; nothing leaves your machine.

> **Beta.** This build has not been tested against a live DCS session yet. Expect rough edges, and please report what you find in Issues.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-0.1.0.exe` below and run it. No admin rights or .NET install needed.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save. The status bar should show *Speech · ready*.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

## What's in it

- **Voice loop:** push-to-talk on any DirectInput button, mic capture from 200 ms before the press, in-app speech recognition biased to your profile's words.
- **Offline speech:** the Whistle model and engine are bundled. English by default; German and others selectable.
- **DCS-BIOS:** commands set cockpit controls directly, wait on cockpit state, and check conditions before acting. Keyboard (scan-code) steps as fallback.
- **Safety:** match threshold of 85, 95 for commands marked critical. Clear "no match" / "refused" audio cues.
- **Profiles:** one per aircraft, switched automatically from DCS, or pinned from the tray. Includes an F-14B Upgraded sample and a common profile.
- **Editor:** phrases with alternatives and spoken values (`{slots}`), step editor, DCS-BIOS control browser with live values, and **Seed…** to generate starter commands from an aircraft's DCS-BIOS definitions.
- **Log and test:** see what was heard, the match and score for every command. Type a phrase to test it, with a dry run option.
- **Installer:** per-user install, Start menu and optional desktop shortcut, sample profiles (never overwrites yours). Settings and profiles are kept on uninstall.

## Known limits

- Not yet run against DCS. The F-14B profile assumes the aircraft name `F-14BU`.
- Windows 10/11 x64 only.
- Installer is not code-signed.
