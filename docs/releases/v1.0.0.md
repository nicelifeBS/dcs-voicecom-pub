First full release of DCS VoiceCom: offline voice control for DCS World. The app can now **talk back**: a new *Say* action speaks a reply with a Windows voice, such as "Radio set to 251.0". A second speech engine, **Zipformer**, hears odd words like "Jester", "AWACS" or "Shkval" much better. This release also adds a keypad check for scratchpad displays like the AH-64D KU, a calmer main window with the log hidden until you need it, and a full reference for the profile file.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-1.0.0.exe` below and run it. It installs over the betas; your settings and profiles are kept.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save.
4. To use server profiles: **Settings → DCS hook → Install**, then restart DCS.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

Profiles from beta 9 work as they are. Two things to check:

- The app now understands **English only**. If you used German or another language, see *Changed* below.
- The debug option to save audio was renamed (see below), so if you had it on, turn it on again in Settings.

## Added

### Zipformer speech engine

- **Settings → Speech engine** picks **Whistle** (default, small and fast) or **Zipformer** (stronger on call signs and odd words).
- On recordings of F-14 Jester commands, Whistle got 20 of 28 right and Zipformer 26, with no wrong command from either. Whistle often hears "Jester" as "Just".
- Zipformer comes with the installer and works offline. It uses about 150 MB more memory than Whistle.
- **Word boost** (Zipformer only, default 1.5) sets how strongly it leans towards your profile's words. Higher can help an odd word, but can also turn other speech into a command word.
- To help it with a word it keeps missing, add the word to the profile's `keywords`.
- If Zipformer can't start, the app uses Whistle and the log says why.

### Voice replies

- **+ Say** in the command editor adds a spoken reply. Use `{slot}` for a spoken value: `Radio set to {freq}`, `Channel {channel}`.
- The reply never holds up the cockpit: the other actions run straight away while the voice speaks.
- **Push-to-talk cuts a reply off**, so the app never talks over your next command.
- **Settings → Voice replies:** turn replies on or off, and pick the language, voice, output device, speed and volume. **Play** tries it out before you save.
- Pick an output device to hear replies in your headset, apart from the game sound.
- Uses the voices built into Windows. No voice for your language? The card says so, and **Open Windows speech settings** takes you to *Manage voices*.
- In a profile file it is `{ "type": "say", "text": "Radio set to {freq}" }`.

### Scratchpad keypad field

- For a display line with a label and a blinking cursor, like the AH-64D KU (`IDENT:ABC#`). In **Enter value → Edit**, make the keypad field the whole line and pick **Scratchpad**.
- The check finds the text after any label (`FREE:`, `UTM LAT/LONG:`) and ignores the cursor.
- Long text may scroll off to the left; then the end of the text is enough.

### Profile file reference

- The [profile format](https://github.com/nicelifeBS/dcs-voicecom/blob/main/docs/profiles.md) now lists every field with its type and default, and has a small JSON example for each step.
- New help page **Profile file** in the app, with a table of all steps.
- New section explaining when to use `bios` and when `bios_until`.

## Changed

- **English only for now.** The language picker in Settings is gone and the app recognizes English, even if your settings file says `de` or another language (the log notes it). More languages will come back in a later version.
- **Numbers read digit by digit now match.** "Radio 251 decimal 000" also works when you say "two five one decimal zero zero zero".
- **Test Coms** uses the speech engine you picked.
- The installer is about 95 MB bigger, for the Zipformer model and its engine.
- **The log is hidden at start.** Click **Log** in the top bar to open it. The app remembers if it was open.
- **The log always shows the newest line**, also right after you open it.
- **Debug audio covers every command.** *Save the audio of every command* (was *Save the audio of missed commands*) saves each push-to-talk clip. Misses start with `Result: MISS` in the `.txt` note. The setting was renamed, so turn it on again if you use it.

## Fixed

- The *Critical* tooltip now says the threshold is an app setting, not a profile setting.

## Known limits

- **English only.** Other languages will come back in a later version.
- **Voice replies need a Windows voice** for your language. Windows comes with voices for its own display language; add others in Windows Settings › Time & language › Speech.
- A voice added while the app runs shows up when you reopen Settings.
- **Server profiles need the DCS hook installed** and DCS restarted once.
- Learn from display needs DCS running and the right display picked. Check the fields and ranges before saving.
- A dial that pushes the rest of the display to the right when it passes 9 (A-10C II FM radio `0-15`, issue 5) can't be learned or used yet. The app tells you why.
- The F-14 UHF preset command is still in the old format.
- A `{text}` slot takes any word, so a misheard word is typed as well. The display check catches it.
- Windows 10/11 x64 only.
- Installer is not code-signed.
