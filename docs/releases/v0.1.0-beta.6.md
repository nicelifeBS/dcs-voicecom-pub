Sixth beta of DCS VoiceCom: offline voice control for DCS World. This release adds a help window inside the app and **Learn from display**, which sets up an Enter value step for you by trying the cockpit controls and watching the display.

> **Beta.** Learn from display was tested with automated tests and simulated displays, not yet in a live DCS session. Check what it fills in before saving, and please report what you find in Issues.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-0.1.0-beta.6.exe` below and run it. It installs over earlier betas; your settings and profiles are kept.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

No breaking changes: profiles from beta 5 work as they are.

## What's new

### Help window

- Press **Help** or **F1** to open it. Topics in groups: first steps, the main window, phrases, actions, seeding, Enter value, matching, troubleshooting, shortcuts and settings.
- **Search** across all pages, links between pages, tip boxes, tables and screenshots you can click to see full size.
- It stays open next to the main window and keeps the last topic until the app quits.

### Enter value: Learn from display

- New **Learn from display…** button in the Enter value window (DCS must be running).
- It lists the controls that might drive the chosen display. Tick the ones to try and press **Start**.
- The app turns each knob or presses each key once, sees which characters change, and fills in the wheels (or keypad keys) and their ranges.
- Afterwards it puts every knob back and clears the entry. **Cancel** does the same.
- It only runs when you press the button. Power, arm, fire and ENT-type controls are never touched.
- A dial shown in two cells (`0-15` as ` 9`, `10`) is learned too, whether the digits sit left or right.

## Known limits

- **Learn from display needs DCS running** and the right display picked. Check the fields and ranges before saving.
- A dial that pushes the rest of the display to the right when it passes 9 (A-10C II FM radio `0-15`, issue 5) can't be learned or used yet. The app tells you why.
- The F-14 UHF preset command is still in the old format.
- A `{text}` slot takes any word, so a misheard word is typed as well. The display check catches it.
- Windows 10/11 x64 only.
- Installer is not code-signed.
