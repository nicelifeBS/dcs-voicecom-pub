Eighth beta of DCS VoiceCom: offline voice control for DCS World. This release brings **shared aircraft profiles**: one profile now covers all variants of a jet.

> **Beta.** Tested in a live DCS session: switching aircraft and their variants, changing servers, and voice commands. Please report what you find in Issues.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-0.1.0-beta.8.exe` below and run it. It installs over earlier betas; your settings and profiles are kept.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save.
4. To use server profiles: **Settings → DCS hook → Install**, then restart DCS.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

No breaking changes: profiles from beta 7 work as they are.

## What's new

### One profile per jet

- The **New profile** list shows one entry per jet, not every name DCS-BIOS knows. It went from 181 names to about 100.
- Variants share a profile: every F-16D and the F-16I use **F-16C_50**, every Tomcat uses **F-14**, every Mirage F1 uses **MirageF1**.
- A profile named after the variant comes first. Type **F-14BU** in New profile, and only the F-14B(U) uses it; the other Tomcats still use **F-14**.
- The log says when a shared profile is used, and the profile list marks it active.
- Jets that only share the generic Flaming Cliffs controls (F-15C, Su-27, …) keep their own profiles.
- `VSN_` mods are left out of the list. You can still type the name.

### Sample profile renamed

- The sample F-14 profile is now called **F-14** and covers every Tomcat.
- An existing `F-14BU` profile stays and still works for the F-14B(U). The installer adds `F-14` next to it.

## Known limits

- **Server profiles need the DCS hook installed** and DCS restarted once.
- Learn from display needs DCS running and the right display picked. Check the fields and ranges before saving.
- A dial that pushes the rest of the display to the right when it passes 9 (A-10C II FM radio `0-15`, issue 5) can't be learned or used yet. The app tells you why.
- The F-14 UHF preset command is still in the old format.
- A `{text}` slot takes any word, so a misheard word is typed as well. The display check catches it.
- Windows 10/11 x64 only.
- Installer is not code-signed.
