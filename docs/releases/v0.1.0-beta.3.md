Third beta of DCS VoiceCom: offline voice control for DCS World. This release adds the **Enter value** step, so you can speak a number and have it dialled into a radio, a preset selector or a keypad.

> **Beta.** Still not tested against a live DCS session. Please report what you find in Issues.

There was no beta 2 release (its build failed), so these notes cover everything since beta 1.

## Install

1. Install [DCS-BIOS (Skunkworks)](https://github.com/DCS-Skunkworks/dcs-bios) in DCS, if you don't have it yet.
2. Download `DcsVoiceCom-Setup-0.1.0.exe` below and run it. It installs over beta 1; your settings and profiles are kept.
3. Start DCS VoiceCom, open **Settings**, set **Push-to-talk → Rebind** and your **Microphone**, then save.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose **More info → Run anyway**.

## What's new

- **Enter value step:** a new step type that turns a spoken value into cockpit input.
  - *Wheels:* splits a number by digit and clicks each wheel until its read-back shows the right digit. Works with spring-loaded wheels like the F-14 UHF set, and wraps around the ends (39 → 22 is one click).
  - *Presets:* a wheel can be read back from a display, e.g. the UHF preset channel (1–20).
  - *Keypad:* presses one key per character.
  - An optional display check confirms the result, and skips the step if the display already shows the value.
- **Enter value window:** add it with **+ Enter value** in the command editor. Fill wheels or keys from the DCS-BIOS catalog, see live read-backs, send test clicks to learn which way a wheel turns, and preview a value without DCS.
- **`{name:text}` slot:** reads spelled NATO letters and digits (e.g. for keypads).
- **F-14B profile:** new `uhf frequency {freq}` and `uhf channel {channel}` commands for the ARC-159.
- **Licence:** DCS VoiceCom is now under the PolyForm Noncommercial 1.0.0 licence. Free for personal, non-commercial use.

## Known limits

- Not yet run against DCS. The F-14B profile assumes the aircraft name `F-14BU`.
- Windows 10/11 x64 only.
- Installer is not code-signed.
