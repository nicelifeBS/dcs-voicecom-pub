# Shortcuts

| Key | Does |
|---|---|
| F1 | Open this help |
| Ctrl+S | Save the profile |
| Ctrl+N | New command |
| F5 | Reload profiles |
| Del | Delete the selected command or profile (asks first) |
| Enter (in the Log box) | Test the typed phrase |
| Ctrl+C (in the Log) | Copy the selected lines |
| Esc | Close this help |
